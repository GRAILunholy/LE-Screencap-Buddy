# LE-Screencap-Buddy
- [Nexus Page](https://www.nexusmods.com/masseffectlegendaryedition/mods/3337)
Adds 2 keybinds for easy conversation screencaps in Mass Effect Legendary Edition

## Usage:
**F10** -> Toggle Scaleform UI: will hide menu buttons, but toggle brings them back

**F8** -> Toggle Lensflare (LE2 & LE3 only): also hides interactive buttons, beware
